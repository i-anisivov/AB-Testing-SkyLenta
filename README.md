# AB-Testing-SkyLenta
# Продуктовая аналитика: A/B тестирование маркетинговых кампаний (SkyLenta)

## Описание проекта
Бизнес-задача заключалась в оценке эффективности нового формата маркетинговых коммуникаций — push-уведомлений в сравнении со стандартными баннерами. Необходимо было провести статистический анализ результатов A/B теста и оценить потенциальный финансовый эффект от внедрения нового формата.

## Стек технологий
* **Язык:** Python
* **Библиотеки:** Pandas, NumPy, SciPy (stats), Matplotlib, Seaborn
* **Доп. инструменты:** Excel (построение калькулятора юнит-экономики)
* **Статистические методы:** T-критерий Стьюдента, Критерий Манна-Уитни, расчет p-value.

## Ключевые этапы работы
1. **Предобработка:** Очистка сырых логов и агрегация данных на уровне пользователей и торговых точек.
2. **Анализ метрик:** Расчет конверсии в покупку (CR) и среднего чека (AOV) для контрольной и тестовой групп.
3. **A/B тестирование:** Проверка статистических гипотез с использованием критерия Манна-Уитни (в связи с ненормальным распределением выручки).
4. **Сегментация:** Углубленный анализ результатов теста в разрезе городов и торговых точек для поиска локальных аномалий.

## Структура репозитория
* `skylenta_ab_test.ipynb` — Jupyter Notebook с полным циклом анализа данных, проверкой гипотез и визуализацией распределений.
* `AB_test_calculator.xlsx` —  Интерактивный калькулятор для оценки потенциального прироста выручки от внедрения push-уведомлений.
